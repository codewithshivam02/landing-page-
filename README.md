# Shipyard 27 — Event Landing Page

A small, responsive landing page for **Shipyard 27**, a fictional two-day student build summit in Pune (20–21 Feb 2027).

Built with plain **HTML, CSS and vanilla JavaScript**. No frameworks, no build step.

## Features
- Responsive layout (desktop → tablet → 390px phone) using CSS Grid/Flexbox and media queries
- Mobile hamburger menu with `aria-expanded`
- Live countdown to doors-open (09:00 IST, 20 Feb 2027)
- Two-day schedule with accessible tabs
- Tracks, speakers, pass tiers with seat bars, FAQ (`<details>`)
- Registration form with client-side validation (no backend; demo only)
- Automatic light/dark theme via `prefers-color-scheme`
- Respects `prefers-reduced-motion`; visible keyboard focus

## Run
Open `index.html` in any browser. To host: push to GitHub → Settings → Pages → deploy from `main` / root.

All names and organisations are fictional.
